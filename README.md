# NexaChat 

-Sistema de chat desenvolvido em Java para a disciplina de programação, utilizando comunicação cliente-servidor.

Funcionalidades

Comunicação entre cliente e servidor utilizando Sockets e Streams.

Conexão simultânea de múltiplos clientes.

Envio e recebimento de mensagens entre os clientes conectados.

Gerenciamento de conexão e desconexão dos usuários.

Utilização de multithreading para atender vários clientes simultaneamente.

Tecnologias utilizadas

Java

Sockets e ServerSocket

Streams de entrada e saída

Threads

IntelliJ IDEA
